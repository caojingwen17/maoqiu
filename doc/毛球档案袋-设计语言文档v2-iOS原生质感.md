## 1. 设计哲学：「像系统一样安静」

v1.0 的问题：暖橘大面积铺色 + 弹跳动效 = 讨好感过重，像营销页，不像每天打开的工具。

v2.0 的答案：**向 iOS 系统语言靠拢**。用户每天要记体重、查提醒，高频工具的舒适感来自"无感"——界面退到内容后面，质感由物理动效和材质细节提供。

> 版本沿革：v2.0 墨绿偏商务沉稳，与宠物主题的"活气"不符；v2.1 抹茶绿提亮后仍带彩色铺色倾向。经 7 套配色方案同原型对比评审，v2.2 最终选定 **G · 米白奶油**：宠物产品的"暖"不靠彩色铺出来，而靠**米白底色烘托**——全产品 95% 面积是米白与炭棕的中性世界，唯一的彩色是焦糖点缀色，只出现在提醒状态、体重变化等"需要被看见"的地方。这是去 AI 味的终极答案：克制到底，温暖自现。

### 1.1 三个关键词

| 关键词 | 含义 |
|---|---|
| **退** | 界面后退一步。大面积中性色，颜色只留给数据和状态 |
| **弹** | 所有运动遵循弹簧物理，没有匀速运动，没有生硬的开始和结束 |
| **真** | 用材质（模糊、发丝线、层级阴影）而非装饰营造品质 |

### 1.2 与 v1.0 的核心差异

| 维度 | v1.0（废弃） | v2.0 |
|---|---|---|
| 主色 | 暖橘大面积铺色 | 炭棕做行动色 + 焦糖做点缀，无彩色铺色 |
| 页面背景 | 奶油暖白 | 米白 `#FAF6EF`（无印良品式的暖白） |
| 卡片 | 大圆角 + 明显阴影 | 小圆角 20rpx + 几乎无阴影，靠底色差分层 |
| 动效 | 回弹弹跳（玩具感） | 弹簧物理（系统感），无 overshoot 夸张的果冻感 |
| 导航 | 自定义标题栏 | iOS 大标题，滚动时收缩 |
| 分割线 | 8rpx 灰带 | 0.5px 发丝线（hairline） |
| 宠物感表达 | 颜色 + 插画 | 只藏在加载动效、空状态、细节文案里 |

### 1.3 设计红线补充（最高优先级）

- **严禁 emoji**：小程序内任何位置——图标、按钮、列表、空状态、正文文案、订阅消息推送、占位符——一律禁止使用 emoji。所有图形表达只有两种合法形式：矢量线性图标（第 9 章）与单色素描插画（5.2）。性别用 ♂ ♀ 字符（系统字体渲染，非 emoji），物种用线性剪影图标。开发自查：提交前全局搜索 emoji unicode 区间，必须为零。

## 2. 色彩系统

### 2.1 主色：炭棕 + 焦糖（Cream Scheme）

这套配色的逻辑是「双主角」：**炭棕承担所有"动作"**（按钮、选中、强调），**焦糖承担所有"提示"**（状态、提醒、点缀）。两者都不大面积铺色，暖意由米白底色负责。

**行动色（炭棕，占"动作"位）：**

| token | 色值 | 用途 |
|---|---|---|
| Primary | `#3E362C` | 实心按钮、选中态、FAB（米白字对比度 11.02:1 ✓ 极优） |
| Primary-Pressed | `#322B22` | 按下态 |
| Primary-Tint | `rgba(62,54,44,0.06)` | 选中行底色、浅底标签 |
| Primary-Mid | `rgba(62,54,44,0.12)` | 进度条已完成段 |

**点缀色（焦糖，占"提示"位，全产品唯一的彩色）：**

| token | 色值 | 用途 |
|---|---|---|
| Pop | `#C08A4E` | 临期状态、体重变化、Tab 选中、图表强调（白底对比度 3.01:1，仅图形/大号文字） |
| Pop-Deep | `#9C6B33` | 焦糖文字版（白底对比度 4.6:1 ✓，小字号文字必须用它） |
| Pop-Tint | `rgba(192,138,78,0.10)` | 提醒胶囊浅底 |

> 选这套的理由：彩色的"宠物感"是第一眼的新鲜，米白的"宠物感"是第三百次打开的舒适。炭棕 `#3E362C` 是比纯黑更暖的深色——纯黑冷，炭棕像旧皮沙发、像咖啡渍，和米白底同属一个温度；焦糖 `#C08A4E` 是全产品唯一彩色，因为稀缺，所以每次出现都有效。**使用纪律**：焦糖只出现在"需要被看见的状态"上（临期、变化、选中），绝不装饰；小字号焦糖文字一律用 Pop-Deep。

## 4. 形状、间距、层级

### 4.1 圆角（收敛到 4 档）

| token | 值 | 用途 |
|---|---|---|
| radius-s | 12rpx | 小标签、Chip |
| radius-m | 20rpx | **卡片标准圆角**（iOS grouped cell 的圆角） |
| radius-l | 28rpx | 输入框、底部弹层顶部 |
| radius-full | 999rpx | 头像、胶囊、浮动按钮 |

> iOS 的精致感来自"小圆角 + 大留白"。24rpx 以上的圆角只在弹层出现。

### 4.2 间距（8rpx 栅格不变，页面边距收紧）

- 页面左右边距：**32rpx**
- 卡片内边距：32rpx 横向 / 28rpx 纵向
- 分组卡片间距：32rpx
- 列表行高：单行 96rpx，双行 128rpx

### 4.3 层级表达（阴影极克制）

| 层级 | 手法 |
|---|---|
| 卡片在页面上 | 无阴影，纯靠 `#FFF` on `#FAF6EF` 的底色差 |
| 悬浮元素（弹层、Action Sheet） | `0 8rpx 40rpx rgba(0,0,0,0.12)` + 顶部 0.5px 高光边 |
| 导航栏/TAB 栏 | 无阴影，毛玻璃材质 + 底部 hairline |
| 深色模式 | 所有阴影移除，卡片改为比页面底亮一阶（`#1C1C1A` on `#0E0E0D`） |

## 5. 材质系统（iOS 质感的核心）

### 5.1 毛玻璃（Vibrancy）

小程序落地方式（无原生 blur 用 CSS 近似）：

```
background: rgba(250, 246, 239, 0.82);
backdrop-filter: blur(20px) saturate(180%);
```

**应用位置（仅 3 处）：**
1. 顶部导航栏（滚动内容从下面穿过时保持可读）
2. 底部 Tab 栏
3. 底部弹层的头部区域

深色模式对应 `rgba(14,14,13,0.78)`。

### 5.2 发丝线（Hairline）

- 所有分割线 0.5px（1rpx 物理像素，用 `transform: scaleY(0.5)` 实现）
- 颜色 Hairline token，不用灰色块、不用间距当分割
- 列表内分割线**左缩进**：从文字起始位置开始，不顶到屏幕左缘（iOS 标志性细节）

### 5.3 按压态（Touch-down 反馈，iOS 列表的灵魂）

- 列表行按下：整行底色变 BG-Fill-Deep，**无缩放**（iOS 列表从不缩放，缩放是 Android/营销页语言）
- 松手后底色 200ms 淡出回白
- 按钮按下：仅颜色加深（Primary→Primary-Pressed）+ 透明度 0.9，**不做 scale 0.97 的弹跳**

## 6. 动效系统：弹簧物理

### 6.1 核心曲线（全局统一，禁用 ease-in-out 匀速感）

| 名称 | 参数 | 用途 |
|---|---|---|
| **iOS Spring** | `cubic-bezier(0.25, 0.1, 0.25, 1)` 500ms | 页面级过渡、弹层、面板 |
| **Snap** | `cubic-bezier(0.2, 0.9, 0.25, 1)` 350ms | 元素位移、高度变化 |
| **Fade** | `ease-out` 200ms | 透明度、颜色 |
| **Press** | `ease-out` 100ms | 按压反馈 |

> 关键原则：**所有动画带一点初速度**（快起慢停），绝不用 slow-start 的 ease-in——这是"丝滑"和"肉"的分水岭。回弹只允许出现在一个组件上（浮动按钮，见 7.9），且幅度 ≤ 3%。

### 6.2 页面转场

- 进入：新页面从右滑入（跟随微信原生，不自定义）
- 弹层：从底部升起 500ms Spring，同时遮罩 0→1 淡入，背后页面**轻微缩小到 0.96 + 圆角**（iOS 模态呈现效果，用 transform 实现）
- 关闭：弹层跟手下拽，速度映射手指速度（惯性关闭）

### 6.3 大标题导航（iOS 标志性交互）

```
未滚动：标题「我的毛孩子们」68rpx/700，位于内容流中
滚动 ↓：大标题随内容上移淡出
滚动超过 88rpx：导航栏中央淡入小标题 32rpx/600 + 毛玻璃背景渐入
回滚到顶：反向动画恢复
```

- 整个过程**跟手插值**（scrollTop 映射透明度/位移），不是两个状态硬切
- 下拉过顶：页面橡皮筋回弹（微信原生 enablePullDownRefresh 的 bounce）

### 6.4 列表重排与增删

- 新增记录插入时间线：上方内容平滑下移 350ms Snap，新行从透明度 0 + 下移 16rpx 的状态归位
- 删除：行高先动画收为 0（内容同时淡出），其余行上移补位
- 卡片拖拽排序：拖拽项放大 1.02 + 阴影出现，其余项让位动画 300ms Snap

### 6.5 触觉反馈

| 场景 | 震动 |
|---|---|
| 开关切换、Chip 选中 | `vibrateShort` light |
| 保存成功、打卡完成 | `vibrateShort` medium |
| 删除确认、校验失败 | `vibrateShort` heavy ×1 |
| 长按照片/卡片 | light |

## 7. 公共组件库（重做）

### 7.1 加载动效 Loading ⭐（本版重点设计）

**方案：线性描边猫爪（Paw Trace）**

一只猫爪的线性图标，加载时描边路径循环"绘制—消失"：

```
爪印由 5 段 path 组成（掌心 + 4 趾）
动画：stroke-dashoffset 从全长 → 0（描边生长 800ms）
     → 停留 200ms → 透明度淡出 300ms → 循环
颜色：Text-Tertiary（静止时）/ Primary（页面级加载时）
尺寸：64rpx
```

- **设计意图**：宠物元素只出现在这里和空状态——用户等待时看到猫爪被一笔笔画出来，是克制的惊喜，不腻
- 局部加载（按钮内）：16rpx 白色描边圆环旋转（iOS spinner 风格，12 根渐隐辐条），不用爪印（太小看不清）
- 全屏加载：爪印 + 下方一行随机小知识轮播（「猫咪每天睡 12~16 小时」），等待变内容

**实现参数：**
```css
.paw-path {
  stroke-dasharray: 260;
  stroke-dashoffset: 260;
  animation: paw-trace 1.3s cubic-bezier(0.4, 0, 0.2, 1) infinite;
}
@keyframes paw-trace {
  0%   { stroke-dashoffset: 260; opacity: 1; }
  60%  { stroke-dashoffset: 0;   opacity: 1; }
  80%  { stroke-dashoffset: 0;   opacity: 1; }
  100% { stroke-dashoffset: 0;   opacity: 0; }
}
```

### 7.2 骨架屏 Skeleton

- 形状与真实布局 1:1（卡片圆角、行高完全一致）
- **微光扫过动画**（shimmer）：一条 120rpx 宽的斜向高光带从左扫到右，1.4s 一轮——比呼吸闪烁更"贵"
- 高光带：`linear-gradient(100deg, transparent, rgba(255,255,255,0.7), transparent)`，深色模式透明度降到 0.08
- 骨架底色：BG-Fill；**禁用任何文字占位符**（"加载中..."三个字是廉价感来源）

### 7.3 输入框 Input ⭐（重做）

**样式（iOS 填充式）：**

```
容器：高 104rpx，radius-l，底 BG-Fill，无边框
内容：上方浮动标签（未输入时 = 占位提示，Body/Text-Tertiary）
      输入后标签上浮缩小为 Footnote/Text-Secondary
      输入值 Callout/Text-Primary
```

**交互：**
- 聚焦：容器底色微加深（BG-Fill-Deep）+ 底部出现 2rpx Primary 横条（从中心向两端展开 250ms Snap）——**不加整体描边**（描边框是表单软件感，下划线才是 iOS 感）
- 标签浮动动画：200ms Fade + 上移 20rpx，跟键盘弹出同步
- 错误态：底部横条变 Danger + 下方 Footnote 红字提示 + 横条轻微闪烁一次（透明度脉冲，**不用左右抖动**——抖动太卡通）
- 清除按钮：聚焦且有内容时右侧出现 32rpx 灰色圆形 ⊗（iOS 标配）
- 数字输入（体重/金额）：唤起自定义键盘，按键高 108rpx，按下时按键底色加深（无缩放），输入值实时以 Title-1 显示在顶部，单位 Caption 置灰跟随

### 7.4 卡片 Card ⭐（重做）

```
背景 BG-Card（深模式 #1C1C1A）
圆角 radius-m（20rpx）—— 比 v1.0 小，精致感来源
内边距：32rpx / 28rpx
阴影：无（悬浮场景才用 4.3 二级阴影）
卡片间关系：同组卡片可合并为"分组列表"（iOS inset-grouped），
           组内行间 0.5px hairline 左缩进分隔
```

**宠物卡片（首页）：**

```
┌─────────────────────────────┐
│ ┌────┐                      │
│ │头像│  豆豆          ♀     │  ← 头像 104rpx 圆角矩形(radius-s)
│ │104 │  英国短毛猫 · 3岁2月  │  ← 名字 Headline，品种 Subhead/Secondary
│ └────┘                      │
│ ─────────── hairline ────── │
│  体重  4.2 kg    疫苗 12天后 │  ← 数据行：数值 Headline + 标签 Footnote
│         ↑0.1kg   (Warning色) │
└─────────────────────────────┘
```

- **双列网格保留**，但卡片从"图片大卡"改为"信息卡"：头像缩小为左上角方形小图，数据成为主角——工具产品信息密度 > 照片展示欲
- 照片依旧想要？头像位支持左右滑动切换最近 3 张照片（滑动时 1:1 吸附，小圆点指示器 8rpx）
- 按下：整卡 BG-Fill-Deep 填充反馈，无缩放
- 临期提醒不用色块条，改为数据行右侧的 Footnote + Warning/Danger 文字色——**全卡片只有一个颜色焦点**

### 7.5 按钮 Button

| 类型 | 样式 |
|---|---|
| Primary | Primary 炭棕实心 + 米白字 `#FAF6EF` 32rpx/600，高 100rpx，radius-l |
| Secondary | Primary-Tint 底 + Primary 字 |
| Plain | 无底无边框，Primary 字（导航栏右侧按钮） |
| Destructive | 无底，Danger 字（iOS 惯例：删除就是一行红字，不做红色实心按钮） |

- 按下：透明度 0.85 + 底色加深，100ms，**无缩放**
- 提交中：文字替换为 spinner（7.1 辐条款），宽度不变（防止按钮跳动）
- 吸底主按钮：底部垫 `safe-area + 32rpx`，按钮上方垫一条从透明到 BG-Page 的渐变遮罩（此处允许渐变，仅作内容淡出遮罩）

### 7.6 列表行 Cell（iOS inset-grouped 标准件）

```
左图标(可选, 48rpx, 类型色/线性) | 标题 Headline        右值 Subhead/Secondary + ›
                                  副标题 Footnote(可选)
```

- 行高：单行 96rpx / 双行 128rpx；热区整行
- 右箭头 `›`：Text-Tertiary，iOS 式细箭头
- 开关行：右侧原生 switch 样式化（开启 Primary，轨道圆角 full，**切换带弹簧动效**——滑块 300ms Snap + 轻微 overshoot）
- 滑动操作（Swipe Actions）：右滑露出操作块，**图标 + 竖排文字**，完成=Success 底、延后=BG-Fill-Deep 底、删除=Danger 底；滑过阈值（40% 宽度）松手自动执行主操作（iOS Mail 式全滑触发）

### 7.7 底部弹层 Sheet

- 顶部 radius-l + 48×6rpx 抓握条（Text-Tertiary 色）
- 升起：500ms Spring + 背后页面缩小 0.96（见 6.2）
- 两个固定高度档：50%（选择器类）/ 92%（表单类），支持从 50% 上推吸附到 92%（拖拽过中点自动吸附，带 Spring）
- 遮罩：`rgba(0,0,0,0.3)`，点按关闭

### 7.8 Toast

- 顶部降下（不是中间弹出）：屏幕顶部安全区下方 16rpx，毛玻璃胶囊 + 左图标右文字
- 动画：从 `-100%` 位置 Spring 降入 500ms，停留 2s，上滑收走
- 成功 = Success 色 ✓（图标 path 绘制动画 300ms）；失败 = Danger 色 ! 
- **一次只允许一条**，新 Toast 顶替旧 Toast（不堆叠）

### 7.9 浮动按钮 FAB（首页「+」）

- 112rpx 圆形，Primary 炭棕实心 + 米白 `+` 字图标
- 阴影：`0 6rpx 24rpx rgba(62,54,44,0.28)`（炭棕染色投影）
- **全产品唯一允许回弹的组件**：按下回弹 3%（250ms 弹性曲线），作为"主要动作"的触觉强调
- 滚动超过一屏缩小为 88rpx，透明度 0.85；回顶恢复

### 7.10 空状态 Empty

- 插画改为**单色素描风**（一种颜色 Primary 的 40% 透明度线条画，不上彩色）：猫爪档案盒、躺平的狗等 6 张
- 标题 Title-3/Text-Primary + 一句说明 Subhead/Text-Secondary + 一个 Secondary 按钮
- 入场：插画轻微上浮淡入 400ms Fade

### 7.11 分段选择器 Segmented Control（iOS 标配件）

- 用于详情页 Tab（时间线/健康/花销/相册）、提醒页（进行中/已完成）
- 容器：BG-Fill 底，radius-s；滑块：白底 + `0 2rpx 8rpx rgba(0,0,0,0.08)` 小阴影
- 切换：滑块 300ms Snap 滑动 + 宽度自适应文字，文字颜色 Text-Secondary → Text-Primary 交叉淡变
- **不再用下划线指示器**（下划线 Tab 是信息流 App 语言，Segmented 才是工具语言）

### 8.1 首页

### 8.4 统计页

- 探针：长按出现竖直 hairline + 顶部数据气泡（白卡小圆角 + 阴影），跟手滑动，松手 300ms 淡出

- 分组：数据管理 / 偏好 / 通用 / 关于，组间 32rpx

### 8.7 深色模式

- 跟随系统为默认；切换时 300ms 全局交叉淡变
- 毛玻璃、发丝线、色板全部走深色 token（2.2/2.3 已定义）

## 9. 图标系统

- **SF Symbols 风格线性图标**：1.5rpx 等宽描边、几何化、转角微圆（不是全圆头，是全直角微圆 2rpx——v1.0 的全圆头太"可爱"，这版要收敛）
- 尺寸：导航 44rpx / 列表 48rpx / Tab 50rpx / 时间线类型图标 56rpx（无底圆形，直接类型色描边图标——去掉 v1.0 的彩色圆底，彩色圆底是仪表盘语言）
- Tab 图标：未选中线性 Text-Tertiary，选中同图形填充 Pop 焦糖色（线性↔填充切换是 iOS Tab 标准做法）
- **严禁 emoji 充当图标或装饰**（见 1.3 红线）：16 个记录类型、4 个 Tab、物种剪影、性别符号（♂ ♀ 用系统字体渲染）、状态标记，全部使用矢量图标文件（svg 或 iconfont），不得以 emoji 字符代替。推送消息文案同样禁用 emoji——用「疫苗提醒：豆豆的狂犬疫苗明天到期」这样的纯文字，比表情符号更庄重
